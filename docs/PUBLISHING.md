Supply both source assets with equivalent access alongside these binaries, including to remote users of the AGPL-covered component. Retain upstream copyright and all component license notices. The repository contains application/submodule snapshots and pinned build recipes; the release corresponding-source archive also carries the larger dependency source inputs. GitHub's automatic source ZIP is not a substitute for those inputs.

The 1.0.0-rc1 binary and corresponding-source archives are the exact previously inspected candidate artifacts. Their internal unpublished/planned labels record their build-time preparation state. Publication-only README/metadata changes in this repository do not alter application sources. verification/BUILD-SOURCE-MANIFEST.json preserves the original snapshot manifest; SOURCE-MANIFEST.json covers this repository snapshot.

Android uses the retained release signer, app ID app.micbridge.stream. Private signing material is not public. Windows remains Authenticode unsigned. Separate physical PC/Android first-install, microphone/playback and network-handoff validation remains pending. The prerelease label reflects that scope.

Future releases must retain source access, revalidate modified artifacts and signatures, and use versioned matching source URLs. Never publish personal runtime state, pairing keys, signing secrets or full local workspace folders.
