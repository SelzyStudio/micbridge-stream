# Exact installer recipe for this revision

MicBridgeHost.nsi and payload.nsh are the exact NSIS sources for this candidate. File inputs use ${PAYLOAD_ROOT}, not a personal absolute path. Populate the payload from the isolated source-built host and web assets using scripts/Prepare-MicBridgeHostPackage.py, then apply packaging/publication/{SOURCE.txt,README.ko.txt,BUILD-INFO.json} and the source notice assets from sources/apollo. Regenerate payload-manifest.json for those exact files. Compile with makensis /DAPP_VERSION=1.0.0-rc1 /DPRODUCT_VERSION=1.0.0.1 /DPAYLOAD_ROOT=<payload> /DOUTPUT_EXE=<new-output> /DGENERATED_INCLUDE=<this-payload.nsh> MicBridgeHost.nsi. Never point output to an existing frozen release. The native host executable and libraries are unchanged from the original rc1 candidate; only external notices and package metadata changed. This source recipe is supplied without claiming bit-for-bit cross-machine reproducibility.
