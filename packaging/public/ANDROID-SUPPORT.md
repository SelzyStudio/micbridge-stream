# 다른 Android폰에서 사용

기종이 정해지지 않았으면 **universal APK**를 사용하세요. ARM64 최신 스마트폰, ARMv7 32비트 구형 기기, x86/x86_64 환경의 라이브러리를 모두 포함합니다. 작은 파일이 필요하면 기기의 ABI와 일치하는 개별 APK를 사용합니다.

선언된 최소 Android 버전은 5.0(API 21), OpenGL ES 3.0입니다. 가상 기기 실행 검증은 Android 6과 Android 15에서 수행했습니다. 모든 제조사·Android 버전·접이식 화면·GPU·마이크 조합을 시험한 것은 아닙니다. 마이크가 없는 기기에서는 마이크 전송을 사용할 수 없습니다.

1. `app.micbridge.stream` 앱을 설치합니다. 기존 Artemis와 별개이며 기존 페어링·설정을 가져오지 않습니다.
2. 새 PC를 추가하고 PIN으로 페어링합니다. PC에서 보기·실행·키보드/마우스/터치 권한을 필요한 만큼 허용합니다.
3. 앱의 마이크 전송 기능을 켜고 Android 녹음 권한을 허용합니다. PC는 Steam Streaming Microphone 입력 장치를 사용해야 합니다.
4. 다섯 손가락을 짧게 탭하고 모두 떼면 터치와 상대 트랙패드 모드가 바뀝니다. 기본 트랙패드 X/Y 감도는 50%입니다.
5. 다른 앱으로 전환하면 영상·PC 소리와 마이크를 쉬고 복귀할 때 재개합니다. 제조사 절전 정책이나 OS 강제 종료는 연결에 영향을 줄 수 있습니다.
6. Wi-Fi↔모바일 데이터는 PC의 도달 가능한 외부 주소/라우팅이 필요합니다. 특정 집의 IP·포트 규칙·인증서·개인 계정은 포함하지 않았습니다.

같은 공개판을 업데이트하려면 동일한 앱 ID·서명 키를 사용한 APK가 필요합니다. 지금 개인 폴드에 설치된 `com.limelight.noirdebug`는 별개이며 이 작업에서 변경하지 않았습니다.
